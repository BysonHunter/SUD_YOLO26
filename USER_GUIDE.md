# Руководство пользователя SUD YOLO26

Описан **новый интерфейс**, запускаемый через `Application/start_workspace.ps1`.
Первоначальная настройка — в [инструкции по установке](INSTALL.md).
Для работы через браузер есть отдельная [инструкция веб-приложения](Web_app/README.md),
включая регистрацию, смену и восстановление пароля и действия администратора.
При обычном запуске главное окно автоматически разворачивается на доступную
область текущего экрана. Его можно восстановить до обычного размера стандартной
кнопкой Windows; панель задач остаётся доступной.

## 1. Рабочий маршрут

1. **Исследование** — открыть DICOM либо ранее подготовленную серию.
2. **Изображения** — подготовить и проверить аксиальную и корональную проекции.
3. **Детектирование** — запустить YOLO26 и проверить рамки.
4. **Анализ камней** — собрать трёхмерные объекты, рассчитать параметры, посмотреть 3D и сохранить PDF.

При наличии сохранённых результатов повторять весь маршрут не нужно.
Автоматический результат требует проверки специалистом.

## 2. Главное окно

| Область | Назначение |
| --- | --- |
| Верхняя строка | «Открыть исследование» и выбор серии среди найденных. |
| Левая панель | Данные пациента и серии, четыре этапа, состояние весов, «Настройки», «Выход». |
| Заголовок этапа | Основная кнопка справа; подпись зависит от этапа и наличия результата. |
| Центр | Изображение или интерактивная 3D-модель, выбор проекции и вида. |
| Под снимком | Имя файла, ползунок слоёв, «Предыдущий» / «Следующий», номер слоя. |
| Правая панель анализа | Выбор почки, камни, сводная таблица, 3D и подробный анализ. |
| Нижняя часть | Состояние операции, индикатор выполнения, отмена и подробности ошибок. |

Границу центральной и правой областей можно перетаскивать. Неактивная кнопка
обычно означает отсутствие нужных данных или выполнение текущей задачи.

## 3. Первый проход: от DICOM до PDF

### 3.1. Открыть DICOM и подготовить изображения

1. На этапе **«Исследование»** нажмите **«Открыть DICOM»**.
2. Выберите папку исходных файлов. При наличии `DICOMDIR` выбирайте содержащую
   его папку, сохраняя структуру подкаталогов.
3. Во втором диалоге выберите каталог сохранения исследований.
4. На этапе **«Изображения»** проверьте показанные пути.
5. Нажмите **«Подготовить изображения»** и дождитесь завершения.
6. Если подготовлено несколько серий, выберите нужную в верхнем списке.

ID пациента, дата и сведения о серии читаются из DICOM: имя пациента, отсутствие
контраста и номер серии вручную не запрашиваются. При наличии `DICOMDIR`
используется его индекс, затем читаются данные выбранных серий; без индекса
программа ищет DICOM-файлы.

Отбор серий автоматический. Предпочтение получают подходящие серии с признаками
нативного исследования в метаданных. Если таких признаков нет, могут обрабатываться
несколько подходящих серий. Проверяйте описание: метаданные не гарантируют отсутствия
контраста. Разные фазы не следует считать одной серией.

Результаты размещаются по схеме `КодПациента/дата_исследования/V001`.
Недопустимые символы идентификатора заменяются безопасным вариантом.

### 3.2. Проверить проекции

1. Выберите **«Корональная»** либо **«Аксиальная»** над снимком.
2. Используйте ползунок, **«Предыдущий»** и **«Следующий»**.
3. Проверьте читаемость и присутствие нужной анатомической области.

Сортировка естественная: `1, 2, 3, …, 10, 11`. Номер в имени — индекс слоя
массива, а не порядковый номер PNG. Подпись «Слой … · … из …» показывает обе величины.

Обе проекции используют общее окно отображения по DICOM-метаданным
с предусмотренным алгоритмом резервным вариантом. Корональные изображения
формируются способом, совместимым с прежним алгоритмом. Отдельная выгрузка
`compatibility` в обычном сценарии не создаётся.

При просмотре снимков на этапах «Изображения», «Детектирование» и «Анализ камней»
при наличии физической геометрии доступны
оси в миллиметрах с началом снизу слева, сетка 5 мм в исходном масштабе и 1 мм
при увеличении, размеры видимого фрагмента. Снимок расположен по центру тёмной
области; тонкая сетка накладывается только на изображение. Шкала Y находится
у левого края области, шкала X — снизу; подписи горизонтальные и автоматически
разрежаются, чтобы не перекрывать друг друга. Основные деления остаются через 5 мм,
промежуточные — через 1 мм.

Кнопка **«Сетка: вкл.» / «Сетка: выкл.»** под изображением включает и отключает
сетку. Выбор сохраняется при перелистывании слоёв и смене проекции в текущем окне;
шкалы, масштаб и размеры фрагмента остаются видимыми. Если масштаб в миллиметрах
неизвестен, кнопка неактивна до задания калибровки.

Панель просмотра позволяет увеличить фрагмент; кнопка с домиком возвращает
исходный вид.

В «Настройках» поле **«Кол-во файлов для выгрузки»** задаёт число корональных
изображений: по умолчанию 200 вокруг центра массива, в пределах доступных слоёв.
Уже сохранённые изображения не меняются. Новый DICOM-экспорт сохраняет PNG;
общее поле формата оставлено для совместимости с прежним интерфейсом.

### 3.3. Выполнить детектирование

1. Откройте этап **«Детектирование»** или нажмите **«Перейти к детектированию»**.
2. Проверьте серию и наличие обученных весов.
3. Нажмите **«Запустить детектирование»**.
4. Дождитесь завершения и перехода в **«Анализ камней»**.
5. Для проверки рамок вернитесь на этап детектирования.

Детектор работает на корональных изображениях. **«Рамки детектора»** включают
и выключают аннотации без повторного запуска модели. Если размеченного PNG
для слоя нет, показывается исходный снимок; слой остаётся в просмотре.

Пороги уверенности: обычный камень **0,3**, коралловидный **0,6**.
Другие параметры — в [config/detection.yaml](Application/config/detection.yaml).
Уверенность YOLO не является вероятностью диагноза. Обучение модели и ручное
редактирование меток из этого экрана не выполняются.

Новый результат публикуется после успешного завершения; прежние детекции
сохраняются механизмом резервирования. После повторного детектирования заново
рассчитайте параметры. Пропуск объекта моделью возможен — проверяйте исходные снимки.

### 3.4. Рассчитать параметры

1. На этапе **«Анализ камней»** нажмите **«Рассчитать параметры»**.
2. Дождитесь сборки камней, расчёта и формирования PDF.
3. Справа выберите **правую** либо **левую почку**.
4. Выберите камень. Нумерация интерфейса начинается с 1.

Снимок переключается на слой выбранного камня, таблица обновляется вместе с ним.
Расчёт использует исходные HU, метки и физическую геометрию, а не яркость PNG.
В области поиска камень выделяется по **HU > 160**; сборка учитывает трёхмерную
связность. Соприкасающиеся области могут стать одним объектом — проверяйте форму в 3D.

Сводная таблица показывает размеры в мм, объём в мм³, массу в граммах и статистики HU.
Габариты и фактический объём — разные характеристики: объём не обязан равняться
произведению габаритов.

При открытии серии сохранённый совместимый расчёт может загрузиться автоматически.
**«Пересчитать параметры»** запускает новый расчёт без использования прежнего
результата; используйте после изменения детекций или параметров сборки.
Если список на выбранной стороне пуст, 3D выбранного камня недоступно. Это описание
результата алгоритма, а не подтверждение отсутствия камней.

### 3.5. Посмотреть 3D

- **«3D выбранного камня»** справа открывает текущий камень внутри окна.
- **«3D почки»** над снимком показывает выбранную почку и плотные включения HU > 160.
- Мышь — вращение, колесо — масштаб.
- **«Снимок»** возвращает к двумерному изображению.

Начальный ракурс почки и камня совпадает с корональным снимком: X направлена
слева направо, Z — снизу вверх, Y — в глубину. Поэтому нижние участки снимка
остаются внизу модели. После открытия модель можно повернуть мышью.

Используются физические расстояния между вокселями. Почка показана в розовых
оттенках, плотные включения выделены отдельно. Визуализация почки — приближение
по HU и обработке маски, а не точная анатомическая сегментация. Прозрачность
слоёв камня помогает видеть внутренние плотные области.

### 3.6. Сохранить PDF

1. После расчёта нажмите **«Сохранить PDF»** вверху справа.
2. Выберите имя и место сохранения.
3. Программа скопирует готовый отчёт и передаст его системному PDF-просмотрщику.

Сохранение доступно и в подробном анализе. PDF формируется существующим модулем
отчётности, поэтому оформление может отличаться от нового окна. Выбор ячейки
лазерной таблицы не меняет отчёт и не назначает режим лечения. Для печати
используйте команду системного PDF-просмотрщика.

## 4. Подробные параметры и время разрушения

Нажмите **«Подробные параметры и расчёт лазера»**. Окно открывается на выбранных
в основном интерфейсе почке и камне.

### 4.1. Выбор объекта

Слева расположены выбор почки и список камней с номером слоя и массой. Вверху —
пациент и карточки габаритов, объёма, массы и среднего HU. Выбор камня обновляет
обе вкладки; для пустой стороны прежние значения очищаются. После возврата
в основное окно выбор почки и камня сохраняется.

### 4.2. «Параметры и изображения»

В списке над изображением:

| Вид | Содержание |
| --- | --- |
| КТ · корональный срез | Слой выбранного камня с доступными рамками. |
| Камень · срез | Увеличенный срез камня. |
| Воксельная модель · HU | Полный объём и вид с удалением 15% массива по каждой оси, окрашенные по HU. |
| Воксельная модель · плотность | Аналогичные виды с отображением групп плотности. |

**«3D камня»** и **«3D почки и камней»** открывают интерактивный вид в той же
области. Выбор изображения в списке возвращает статический просмотр.
Сетки и инструментов масштаба для КТ в этом окне нет.

Справа — габариты, фактический и ограничивающий объёмы, масса по вокселям
и по средней плотности, средняя плотность, статистики HU, число и объём вокселей,
диапазон слоёв включительно. Точность, достоверность и правдоподобие обозначены
**«Не вычислено»**, если показателей нет; уверенность YOLO их не подменяет.
При небольшом окне прокрутите таблицу.

### 4.3. «Время разрушения»

Расчёт относится к модели гольмиевого лазера 2,1 мкм.

1. Выберите камень.
2. Найдите энергию в строках: **0,6–2,4 Дж**, шаг 0,1 Дж.
3. Найдите частоту в столбцах: **8–15 Гц**, шаг 1 Гц.
4. Нажмите ячейку.
5. Справа прочитайте энергию, частоту, мощность `E × f` в Вт и расчётное время.

Цвет фона и текста каждой ячейки совпадает с PDF-таблицей. Наведите указатель,
чтобы увидеть название режима по цветовой легенде, энергию, частоту и время.
Выбранная ячейка выделяется рамкой, сохраняя исходный цвет; название её режима
дублируется справа. Кнопка «Легенда режимов» открывает все восемь названий.
При смене камня энергия и частота сохраняются, время пересчитывается по его массе.
Таблица прокручивается.

Легенда: синий — дробление осколков; голубой — камни с низкой плотностью;
бирюзовый — неудобные подходы инструмента; тёмно-бирюзовый — «Оптимальный режим
работы»; зелёный — высокая плотность; светло-зелёный — высокий риск травмы;
фиолетовый — малоэффективный режим; розовый — малоэффективный, не рекомендованный
к применению. В PDF десять оттенков: дополнительный синий объединён с низкой
плотностью, сине-фиолетовый — с дроблением осколков.

Названия являются расшифровкой предоставленной цветовой легенды. Интервал цвета
выбирается по расчётному времени текущего камня; отдельная оценка риска,
плотности для выбора режима или клинической пригодности алгоритмом не выполняется.

**«Показать формулу и исходные данные»** раскрывает:

```text
t = m / (γ × E × f)
γ = 0,4
m — рассчитанная масса камня, г
E — энергия импульса, Дж
f — частота, Гц
```

Значения округляются до двух знаков и совпадают с моделью PDF-отчёта.
Размерность γ в исходной модели не задана, поэтому время подписано как
**«единицы исходной модели»**, без утверждения о секундах или минутах.
Нечёткая классификация R1–R8 здесь не реализована. Клиническая интерпретация
требует отдельного уточнения и валидации модели.

### 4.4. Возврат

**«Вернуться к исследованию»** или закрытие окна возвращают в основное рабочее
пространство. **«Сохранить PDF»** находится в верхней строке.

## 5. Повторно открыть исследование

1. Нажмите **«Открыть исследование»** вверху либо **«Открыть готовое исследование»**
   на стартовом экране.
2. Выберите каталог серии `V001`, его `images/coronal` или `detect`.
3. Можно выбрать родительскую папку современных экспортированных серий:
   найденные серии появятся в верхнем списке.
4. Выберите серию и дождитесь проверки сохранённого результата.
5. При необходимости перейдите в детектирование или анализ.

Если расчёта нет, но есть метки, выполните «Рассчитать параметры». Если детекций
нет — сначала детектирование. Старый формат с `*arrayinfo.csv` и `*array.npy`
поддерживается при выборе его каталога.

## 6. Сохранение и перенос данных

Сокращённая схема; ID и дата условные:

```text
каталог_результатов/
└── PATIENT_ID/
    └── 20200101/
        └── V001/
            ├── selection.json
            ├── window.json
            ├── geometry/
            │   └── geometry.json
            ├── volume/
            │   └── hu_lps.npy
            └── images/
                ├── axial/
                └── coronal/
                    ├── PATIENT_ID_20200101_cor_250.png
                    ├── detect/
                    │   └── labels/
                    └── stones/
```

Есть и дополнительные служебные файлы. Имена изображений:
`ID_дата_axe_слой.png` и `ID_дата_cor_слой.png`. Дата имени относится к получению
изображения и может отличаться от даты исследования в имени папки.

**Переносите весь каталог серии** с дополнительными файлами. PNG и меток без
HU-массива и геометрии недостаточно для физических параметров и 3D. PDF подходит
для чтения, но не для повторного анализа. Не переименовывайте слои и не смешивайте
части разных серий. После переноса откройте новый путь; если старый кэш или его
ресурсы недоступны, выполните «Пересчитать параметры».

Не запускайте одновременно запись нескольких экземпляров приложения в одну серию.
Имена и метаданные содержат идентификаторы пациента — учитывайте это при передаче.

## 7. Настройки, отмена и выход

**«Настройки»** внизу слева открывают пути, число корональных изображений
и общие параметры совместимости. Они сохраняются в `config/settings.yaml`.
Изменение пути не переносит существующие данные. Настройки CPU/GPU и детектора —
в [config/detection.yaml](Application/config/detection.yaml).

Во время задачи следите за строкой состояния. Индикатор без известного общего
числа отражает выполнение, а не зависание. Часть элементов заблокирована,
чтобы не менять обрабатываемое исследование.

- DICOM и детектирование можно отменить кнопкой **«Отмена»**. Безопасная остановка
  может занять время.
- Расчёт параметров не имеет отмены — дождитесь завершения.
- Повторный запуск после отмены не следует считать продолжением с места остановки.
  Временные папки не являются готовыми результатами.
- **«Выход»** слева внизу и закрытие главного окна завершают приложение.
  При активной задаче окно остаётся открытым и предлагает дождаться окончания
  или сначала отменить доступную операцию.

## 8. Если возникла проблема

| Ситуация | Что проверить |
| --- | --- |
| Нет пригодной CT-серии | Папку, структуру DICOMDIR, наличие КТ и декодеров. |
| Веса найдены, но модель не запускается | Индикатор проверяет наличие файла; архитектура и классы проверяются при загрузке. Установите подходящий checkpoint. |
| Расчёт недоступен | Выбрана ли серия, есть ли `detect/labels/*.txt`, завершилась ли текущая задача. |
| Список камней пуст | Сторону почки, рамки и завершение расчёта; это не доказывает отсутствия камней. |
| Ошибка массива, геометрии или слоя | Полноту экспорта и соответствие меток; после исправления пересчитайте параметры. |
| Нет статического изображения | Целостность `stones`; пересчитайте параметры. При наличии массива попробуйте 3D. |
| 3D не открывается | Зависимости, графический драйвер и обычный графический сеанс; см. [установку](INSTALL.md). |
| Нужен снимок вместо 3D | «Снимок» в основном окне или список изображений в подробном. |
| Время без секунд/минут | Так отражена неопределённая размерность γ; пояснение под формулой. |

При ошибке появляется блок с сообщением и техническими подробностями. Сохраните
текст, этап и версию программы; перед передачей удалите идентификаторы пациентов.
