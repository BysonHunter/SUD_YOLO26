Удалить пользователя?

Вход будет запрещён, открытые сеансы завершатся. Исследования сохранятся на сервере. Удалённый логин останется зарезервированным.

УЧЁТНАЯ ЗАПИСЬ

После сброса старый пароль не даст доступа к исследованиям. Пользователь должен создать новый по одноразовой ссылке; все его сеансы завершатся.

Если письмо не доставлено, передайте ссылку пользователю лично по защищённому каналу. При смене email или повторном сбросе ссылка перестанет действовать.
