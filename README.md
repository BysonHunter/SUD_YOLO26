# SUD YOLO26

Настольная программа для подготовки КТ-изображений из DICOM, обнаружения почек
и камней обученной моделью YOLO26, расчёта параметров камней и трёхмерного просмотра.

## Инструкции

- [Установка и запуск](INSTALL.md) — требования, CPU/GPU, установка весов, проверка и обновление.
- [Руководство пользователя](USER_GUIDE.md) — подробная работа в новом интерфейсе от DICOM до PDF.
- [Веб-приложение](Web_app/README.md) — Docker, учётные записи, загрузка DICOM-архивов,
  просмотр изображений и 3D, расчёты и скачивание PDF через браузер.

В веб-приложении доступны самостоятельная регистрация с email и собственным
паролем, кабинет администратора со всеми исследованиями и владельцами,
архив исходных ZIP с повторным анализом и шифрование ZIP перед отправкой.
Для доступа по сети требуется HTTPS.

Новый интерфейс: «Исследование → Изображения → Детектирование → Анализ камней».
Прежний интерфейс сохранён; оба используют общие настройки и алгоритмы.

## Быстрый запуск

Обученная [модель YOLO26s](Application/weights/kidney_yolo26.pt) включена
в репозиторий и расположена по стандартному пути приложения. Контрольная сумма
и сведения о модели — в [манифесте](Application/weights/model_manifest.json).
После установки зависимостей отдельно устанавливать веса не требуется.

После установки запуск из каталога `Application`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_workspace.ps1
```

В репозитории находятся программа, обученная модель, инструкции и видеопример на реальной КТ-серии.
Исходные DICOM, датасеты и рабочие каталоги обработки не публикуются. Обработка выполняется
локально. Результаты требуют проверки специалистом; техническая работоспособность
не означает клиническую валидацию.
