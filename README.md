# SUD YOLO26

Настольная программа для подготовки КТ-изображений из DICOM, обнаружения почек
и камней обученной моделью YOLO26, расчёта параметров камней и трёхмерного просмотра.

## Инструкции

- [Установка и запуск](INSTALL.md) — требования, CPU/GPU, установка весов, проверка и обновление.
- [Руководство пользователя](USER_GUIDE.md) — подробная работа в новом интерфейсе от DICOM до PDF.

Новый интерфейс: «Исследование → Изображения → Детектирование → Анализ камней».
Прежний интерфейс сохранён; оба используют общие настройки и алгоритмы.

После установки запуск из каталога `Application`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_workspace.ps1
```

В репозитории находятся программа и инструкции. Данные пациентов, DICOM,
датасеты, веса и результаты обработки не публикуются. Обработка выполняется
локально. Результаты требуют проверки специалистом; техническая работоспособность
не означает клиническую валидацию.
